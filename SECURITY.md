# Security

This code takes and moves money. Please report a vulnerability privately: open a
[GitHub security advisory](https://github.com/quebracho-digital/x402-rs/security/advisories/new)
on this repository. Do not open a public issue for it.

Say what an attacker can do (deliver without paying, charge twice, pay a sanctioned address, crash a
seller...), how to reproduce it, and which commit you tested.

What is defended, threat by threat, and what is knowingly out of scope: `planning/THREATS.md` and, for
the behaviour shared with the PHP library, its
[protections](https://github.com/quebracho-digital/x402/blob/main/docs/protections.md).

The code has not had an independent security audit yet.
